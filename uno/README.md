# UNO Online

一个零后端、适合朋友之间临时开局的浏览器 UNO 联机桌。

## 功能

- 2–4 人在线联机
- 6 位房间码 + 可分享邀请链接
- 房主浏览器维护权威牌局状态
- WebRTC 点对点数据连接
- 标准 108 张牌组
- 数字牌、跳过、反转、+2、万能、万能 +4
- 万能 +4 出牌限制
- 摸牌后可打出刚摸到的牌或结束回合
- 断线暂停与同身份重连
- 手机 / 桌面响应式界面

## 运行方式

这是单文件静态网站，直接通过 HTTPS 静态托管 `index.html` 即可。

联机使用 PeerJS 公共信令服务。WebRTC 点对点连接在某些严格 NAT、校园网或公司网络环境中可能受限；房主离开或关闭页面后，本局房间会结束。
